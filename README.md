# DT068G - Web Usability

Design, Implementation, and Evaluation of Websites with a Focus on Usability and Accessibility.

This course was primarily theoretical, focusing on usability and accessibility in web development. I worked with target group analysis, graphic profiles, prototypes, usability testing, and various other techniques to create a user-friendly website. For the final project, I developed a website for online booking of transportation services and administration of transport users.
